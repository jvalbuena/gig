## Job description (key requirements)
AI Build Lead = single point of accountability for end-to-end delivery of complex AI
projects, "voice of the customer," from scoping through post-delivery. Product-owner /
BA / delivery-lead hybrid. Named responsibilities: map customer journeys, scope Use
Cases, own as-is process docs + scoping workshops, translate needs into AI solution
design, early-warning on scope/budget risk, partner with Engineering on API discovery /
NFRs / feasibility, lead agile ceremonies + user stories + backlog, milestone lo-fi
demos, coordinate UAT end-to-end + own Go/No-Go, primary customer-facing lead, weekly
status cadences, partner with Engagement Leads on the delivery roadmap.
- Must-haves: **8+ yrs as BA / Technical Consultant / Product Owner / PM / delivery-
  focused role in a tech or AI environment**; working understanding of APIs + data
  schemas, engage credibly with technical counterparts; represent data models to
  enable mock data; deep agile (sprint ceremonies + backlog end-to-end); primary
  customer liaison on complex projects; facilitate requirement/scoping workshops
  (templates, mappings, process docs); coordinate UAT; translate ambiguous needs →
  requirements / user stories / AI solution; strong written+verbal comms + demos;
  fast-paced high-accountability; **Jira + Confluence**.
- Preferred: enjoys fast results / continuous improvement / scaling; confident with
  customers when things get tough.
