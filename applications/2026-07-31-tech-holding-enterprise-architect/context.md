## Job description (key requirements)
Enterprise Architect embedded on a client engagement. Assess current systems, define
**future-state architecture**, produce **roadmaps + decision records + diagrams**,
translate business priorities into architecture, and communicate to executives /
product / engineering / delivery. Trusted-advisor, **client-facing consulting** role.
Required: senior architecture role (EA / Solution / Principal Architect); digital
products / enterprise platforms / complex ecosystems; modern software architecture,
cloud platforms, APIs, integrations, data flows, enterprise systems; connect business
↔ tech; senior-stakeholder engagement; guide teams **without being day-to-day
manager**; comfortable in **client-facing consulting / professional services**.
Nice-to-have: **real estate / proptech (highly preferred)**; GCP; TypeScript/Node/
modern web / cloud-native; product modernization / platform consolidation / digital
transformation; security / compliance / data governance / EA frameworks; prior
consulting / advisory.
Firm values: deep expertise, integrity, transparency, **dependability**.
