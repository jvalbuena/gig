## Job description (key requirements)

AppDynamics to Elastic Observability using OpenTelemetry. Define OTEL-first
instrumentation standards and scalable telemetry pipelines. Drive SRE practices

Observability (APM, traces, logs, metrics, service maps); deep Kibana dashboarding;
ESQL query writing; IaC/CI-CD/API automation; SRE practices (SLIs/SLOs, incident
diagnostics); governance/cost/risk mindset; Agentic AI capability building.
