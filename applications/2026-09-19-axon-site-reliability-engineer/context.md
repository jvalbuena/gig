- **Date**: 2026-09-19   **Status**: drafted
- **Source**: pasted

## Job description (key requirements)
Remote anywhere in Australia. Contribute to building/maintaining reliable,
scalable, secure cloud platforms and tools; apply SRE principles; write clean
maintainable code; troubleshoot distributed cloud-native systems; participate
in on-call/incident response. 2-5 years experience in software engineering,
SRE, or infrastructure. Required: Linux; cloud platforms (Azure/AWS);
Kubernetes (AKS/EKS); one programming language (Python/Go/C#/Java); CI/CD and
automation; observability tools (logging, metrics, APM); IaC exposure
(Terraform/ARM); Australian government security clearance or ability to
obtain (Australian citizenship required).
